# セキュリティポリシー

Navide はデスクトップアプリ（Electron＋ローカル Python バックエンド）と、任意で利用する
リレーサーバー（Navide Cloud）で構成されています。

## 脆弱性の報告

このリポジトリの Security タブにある GitHub の **「Report a vulnerability」**（非公開報告）
からご連絡ください。悪用され得る問題は公開 issue にしないでください。

役立つ情報：バージョンとプラットフォーム、再現手順または引き金となるリクエスト／メッセージ、
攻撃者が得られるもの、どこから攻撃できるか（リモートのピア、同一マシンの別アカウント、
同一ユーザーのプロセス、ウィンドウ内の信頼できないコンテンツ）。

## 対応の目安

- 3 営業日以内に受領をお知らせします。
- 7 営業日以内にトリアージと重大度の判定を行います。内部監査と同じ脅威モデルを用います。
- 高・重大は次のリリースで修正し、それ以外はまとめて対応します。修正後にご連絡し、
  ご希望がなければリリースノートで謝辞を記載します。

## 対象範囲

対象：このリポジトリ、Navide デスクトップアプリ、`server.navide.dev`。
対象外：Navide が起動するサードパーティ CLI（上流へ報告してください）、ロック解除済みの
マシンへの物理アクセスを要する事象、`contextIsolation`／`sandbox`／コード署名を意図的に
無効化した場合にのみ成立する事象。

## 善意の調査

上記範囲内で、プライバシーを侵害せず、サービスを妨げず、開示前に妥当な修正期間を
与えていただける調査に対して法的措置は取りません。本番サーバー上の他者のアカウントや
デバイスに対するテストは行わないでください。サーバーはローカルで実行できます。

## サポート対象バージョン

最新の署名済みリリースのみがセキュリティ修正の対象です。
