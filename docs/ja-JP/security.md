# セキュリティポリシー

このページはルートの [SECURITY.md](../../SECURITY.md) の要約訳です。英語版を正とします。

## サポート対象バージョン

Navide は現在 1.0 未満です。セキュリティ修正は `main` の最新コードと最新リリースを対象とし、古いスナップショットへの修正は保証されません。

## 脆弱性の報告

疑わしい脆弱性について公開の GitHub Issue を作成しないでください。**nt.nerdtechnic@gmail.com** 宛に、次の件名でメールしてください。

```text
[Navide] Security Vulnerability
```

説明、再現手順、想定される影響、影響を受けるバージョンまたはコミット、可能であれば修正案を添えてください。認証情報、非公開ソースコード、無関係な個人情報は報告から除いてください。

48 時間以内の受領連絡、7 日以内の状況報告を目標としています。これは対応目標であり、期限内の解決を保証するものではありません。

## 対象範囲と善意の調査

対象：このリポジトリ、Navide デスクトップアプリ、`server.navide.dev` の Navide Cloud リレー。対象外：Navide が起動する外部 CLI（上流へ報告してください）、ロック解除済みマシンへの物理アクセスを要する事象、`contextIsolation`／`sandbox`／コード署名を意図的に無効化した場合にのみ成立する事象。

範囲内で、プライバシーを侵害せず、サービスを妨げず、開示前に妥当な修正期間を与える善意の調査に対して法的措置は取りません。本番リレー上の他者のアカウントやデバイスに対するテストは行わないでください。サーバーはローカルで実行できます。

## セキュリティモデル

Electron アプリ、Python バックエンド、PTY、オーケストレーション状態、ワークスペースデータはユーザーのマシン上で動作し、バックエンドは loopback のみを待ち受けます。各セキュリティレビューで照合する攻撃者の位置と、それに対応する制御は [Security threat model](../en-US/security-threat-model.md) に記載しています。認証情報、エージェント権限、Git 許可リストの境界、ハンドオフとログ、外部連携、既知の制限は英語版を参照してください。
