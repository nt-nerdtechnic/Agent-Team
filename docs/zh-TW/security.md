# 安全政策

Navide 是一個桌面應用（Electron＋本機 Python 後端），加上可選的中繼伺服器（Navide Cloud）。

## 回報弱點

請透過本 repository 的 Security 分頁使用 GitHub 的 **「Report a vulnerability」**（私密回報）。
任何可能被利用的問題，請不要開公開 issue。

有助於我們快速處理的資訊：版本與平台、重現步驟或觸發的請求／訊息、攻擊者能得到什麼、從哪裡發動
（遠端對端、本機其他帳號、同使用者的行程、視窗內不受信內容）。

## 你會得到的回應

- 3 個工作天內回覆收到。
- 7 個工作天內完成分級。我們用與內部稽核相同的威脅模型。
- 高與嚴重等級在下一個版本修復，其餘批次處理。修好會通知你，並在版本說明中致謝（除非你不希望）。

## 範圍

包含：本 repository、Navide 桌面應用、`server.navide.dev`。
不包含：Navide 啟動的第三方 CLI（請向上游回報）、需要實體接觸已解鎖機器的情境、
刻意關閉 `contextIsolation`／`sandbox`／簽章才成立的發現。

## 善意研究

在上述範圍內、不侵犯隱私、不影響服務、給我們合理修復時間再揭露的研究，不會被追究。
請不要對正式伺服器上他人的帳號或裝置做測試；伺服器可在本機執行。

## 支援版本

只有最新的簽章版本會收到安全修復。
